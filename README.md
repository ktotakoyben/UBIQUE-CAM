# OBS CamMorph (v0.1 MVP)

Нативный видеофильтр для OBS Studio с GPU-шейдером (HLSL):
- Скругление углов (SDF, идеальное сглаживание)
- Зум и сдвиг (Pan X/Y)
- Кроп со всех 4 сторон
- Рамка + внешнее свечение (Glow) с выбором цвета
- Отбрасывание мягкой тени (Drop Shadow) с автоматическим расширением границ (тень не обрезается)

## Как собрать `.dll` через GitHub Actions (без установки Visual Studio)

1. Создай новый репозиторий на GitHub (можно приватный).
2. Загрузи все файлы из этого архива в корень репозитория (важно сохранить папку `.github/workflows/build.yml`).
3. Перейди во вкладку **Actions** в своём репозитории.
4. Дождись окончания сборки **Build OBS CamMorph Plugin (Windows x64)** (~2–3 минуты).
5. Внизу страницы сборки скачай артефакт **`obs-cam-morph-windows-x64`**.

## Установка в OBS Studio

1. Распакуй скачанный архив `obs-cam-morph-windows-x64.zip`.
2. Скопируй папки `obs-plugins` и `data` прямо в папку установки OBS Studio (обычно `C:\Program Files\obs-studio\`) слиянием папок.
3. Запусти OBS → выбери вебку (или любой источник) → **Фильтры** → **Фильтры эффектов** → **+ → CamMorph: Стилизация вебкамеры**.
