# UBIQUE CAM

Нативный GPU-плагин для **OBS Studio** (Windows x64), объединяющий стилизацию вебкамеры, полноценный **PNGTuber-движок**, **Audio Spectrum** и сохранение аппаратных настроек USB-камер (включая Logitech) в одном фильтре без стороннего софта.

Интерфейс выполнен в тёмной минималистичной эстетике **Lithic** (вдохновлён *ryoku.dev*) и полностью переведён на русский язык.

---

## Основные возможности

### 1. Камера, оптика и пресеты формы
* **10 готовых пресетов формы:** *Круг*, *Квадрат 1:1*, *Классика 4:3*, *Портрет 3:4*, *Кино 16:9*, *Шортс 9:16*, *Ультра 21:9*, *Капсула*, *Крупный план*, *Сброс*.
* **Геометрия на GPU (SDF):** идеально гладкое скругление углов, зум, сдвиг (Pan X/Y) и независимый кроп с каждой стороны.
* **Оптика:** зеркалирование по горизонтали (`Flip H`), виньетка, контраст и теплота цвета.

### 2. Рамка, свечение и тень
* **5 готовых пресетов стиля:** *Lithic*, *Clean*, *Неон*, *Тактик*, *Стикер*.
* **Гибкая рамка:** сплошной цвет, двухцветный градиент или анимированный вращающийся градиент.
* **Аудио-реактивное свечение:** реакция радиуса и яркости свечения на микрофон + отдельный **цвет вспышки на пиках** (при крике).
* **Drop Shadow:** настраиваемая мягкость, сдвиг по X/Y и цвет тени.

### 3. Переключение режимов «Камера ↔ PNGTuber»
* Переключение по горячей клавише (`UBIQUE CAM: Переключить Камера / PNGTuber`), из окна фильтра или через встроенную док-панель.
* **4 анимации перехода:** *Плавный (Crossfade)*, *Размытие (Blur Morph)*, *Глитч (Glitch / RGB Split)* и *CRT-схлопывание*.

### 4. Встроенный PNGTuber-движок
* **4 состояния модельки** с удобной загрузкой через **Drag & Drop** (ПКМ по слоту — очистить): *Молчит*, *Говорит*, *Моргает*, *Говорит + Моргает*.
* **Живой сегментный VU-метр** с индикатором порога срабатывания и задержкой закрытия рта (Talk Hold).
* **Процедурные GPU-анимации:** дыхание, подпрыгивание при начале речи, плавное покачивание, авто-моргание.
* **Дополнительные эффекты:** тряска при крике (*Scream Shake*) и затемнение при молчании (*Idle Dim*).
* **4 варианта фона:** сплошной цвет, картинка, размытая вебкамера или полностью прозрачный фон.

### 5. Audio Spectrum (32-полосный GPU-визуализатор)
* **Отдельный источник звука:** можно привязать к микрофону или к музыке (например, браузер/Spotify).
* **4 положения в слое:** *Выключен*, *За моделькой (PNGTuber)*, *Поверх изображения*, *По периметру рамки*.
* **4 дизайна волны:** *Классические столбики (Bars)*, *Плавная неоновая волна (Wave)*, *Зеркальная от центра (Mirrored)*, *LED-сегменты (Lithic)*.

### 6. Сейв аппаратных настроек камеры (DirectShow)
Решает проблему постоянного сброса настроек на вебкамерах **Logitech** (StreamCam, C920, C922, Brio и др.) после перезапуска Windows или OBS.
* Сохраняет и восстанавливает экспозицию, фокус, баланс белого, яркость, контраст, насыщенность, резкость, усиление (Gain) и зум **вместе с флагами Авто/Ручной**.
* **2 аппаратных слота:** *День* и *Вечер / Лампа*.
* **Авто-восстановление при запуске OBS:** выбранный слот автоматически применяется к камере после старта.

### 7. Удобство управления
* **Чистое окно фильтра в OBS:** только выбор режима и кнопка **«Настройка UBIQUE CAM»**.
* **Встроенная док-панель OBS** (*Док-панели → UBIQUE CAM*): тумблер `КАМЕРА / PNGTUBER`, живой VU-метр, кнопки быстрого возврата настроек камеры (`↺ День` / `↺ Вечер`) и быстрый доступ к настройкам.
* **3 пользовательских слота профилей** фильтра (сохраняются прямо в сцене OBS).

## Установка

1. Скачай готовый архив `ubique-cam-windows-x64.zip` из вкладки **Actions** (последняя успешная сборка).
2. Полностью закрой **OBS Studio**.
3. Распакуй папки `obs-plugins` и `data` из архива в корневую папку OBS (обычно `C:\Program Files\obs-studio\`) с заменой файлов.
4. Запусти OBS, открой **Фильтры** источника вебкамеры → нажми `+` → выбери **UBIQUE CAM**.
5. *(Опционально)* В верхнем меню OBS включи **Док-панели → UBIQUE CAM**.

## Сборка через GitHub Actions

Сборка настроена на ручной запуск (`workflow_dispatch`), чтобы не тратить минуты Actions при каждом коммите:

1. Перейди во вкладку **Actions** в репозитории.
2. Выбери workflow **Build UBIQUE CAM Plugin (Windows x64)**.
3. Нажми **Run workflow** → **Run workflow**.
4. После завершения сборки скачай артефакт **`ubique-cam-windows-x64`**.

## Системные требования

* **ОС:** Windows 10 / 11 (64-bit)
* **OBS Studio:** 30.x – 33.x (Qt6)
* **Стек:** C11 / C++17, `libobs`, `obs-frontend-api`, Qt6, HLSL, Windows DirectShow API
